# 7zy X

Painel de otimização para Windows, reconstruído como projeto original em C#/.NET WPF.

## Primeira versão
- Login com Admin e Comprador.
- Visual branco + dourado.
- Home e Optimization.
- Presets Basic, Optimal e Maximum PRO.
- Apply e Revert.
- Porcentagem de otimização baseada em ajustes detectados.
- Ajustes reais e reversíveis do Windows.
